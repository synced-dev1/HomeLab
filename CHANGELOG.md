# HomeLab User Changelog

User-visible updates, grouped by product component. Technical implementation history is kept in [DEVELOPER_CHANGELOG.md](DEVELOPER_CHANGELOG.md).

## API — Current prototype

- Added account registration and sign-in.
- Added authenticated chunked uploads to storage on the host computer.
- Added file and folder records, including uploaded file sizes.
- Added a colorful HomeLab banner when the API starts.
- Added Basic Security

## Website — Planned

- A website for browsing and downloading stored files is planned, but is not available yet.

## Known API limitations

- Upload size is not limited yet.
- The API is still an early prototype for a trusted home network.
- A downloadable executable has not been published yet.
